# Pockethernet v1 firmware v33 web updater

⚠️ Use at your own risk.

This is an unofficial web based updater for Pockethernet v1 firmware v33.

The user must select the official Pockethernet Linux updater file locally. The file is processed in the browser and is not uploaded to a server.

## Requirements

Chrome or Edge on macOS with Web Serial support.

The uploaded file name must be exactly:

```text
pockethernet-v33-fwupgrade
```

Download the official updater from:

https://pockethernet.com/firmware.html
